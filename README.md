# Osbert Pro Portfolio

A lightweight static portfolio website built with HTML, CSS, and vanilla JavaScript.

## Project files

- `index.html` — page content, metadata, and structured data.
- `style.css` — layout, responsive styles, and visual design.
- `script.js` — navigation, map comparison, testimonial carousel, and contact-link carousel behavior.
- `LOGO.PNG`, `Portrait.png`, `favicon.svg` — brand and profile assets.
- `maps 1.jpg`, `maps 2.jpg` — before/after map comparison images.
- `gsc-organic-chart.jpg`, `gbp-insights-dashboard.jpg`, `google-ai-overview-citation.jpg`, `google-serp-3pack.jpg` — local SEO proof images.
- `portrait 1.png`, `portrait 2.jpeg` — about-section portraits.
- `robots.txt`, `sitemap.xml` — search crawler guidance and sitemap.

## Maintenance notes

Keep image filenames in sync with their references in `index.html`. Before removing an asset, search `index.html`, `style.css`, and `script.js` for its filename. The site currently serves these files from the repository root, so moving assets into folders requires updating their paths in the HTML and CSS.
