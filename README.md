# Osbert Pro Portfolio

A lightweight static portfolio website built with HTML, CSS, and vanilla JavaScript.

## Project structure

- `index.html` — page content, metadata, and structured data.
- `assets/css/style.css` — layout, responsive styles, and visual design.
- `assets/js/script.js` — navigation, map comparison, testimonial carousel, and contact-link carousel behavior.
- `assets/images/` — logo, portraits, favicon, map comparison, and local SEO proof images.
- `robots.txt`, `sitemap.xml` — search crawler guidance and sitemap.

## Maintenance notes

Keep asset paths in `index.html` and CSS synchronized with the filenames in `assets/images/`. Before removing an asset, search the project for its filename. The site is static and does not require a build step.
